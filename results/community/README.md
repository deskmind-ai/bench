# Community results · 社区成绩

Results submitted by others, one folder per harness version: `<suite_version>/<label>.json` (the entry) and
`<label>.summary.json` (the summary `deskmind-bench run` or `deskmind-bench score` wrote). The schema and the rules
(same suite hash and harness version, n ≥ 3, per-task counts, env errors apart, serving setup) are in
[CONTRIBUTING.md](../../CONTRIBUTING.md#how-to-submit-results).

Numbers here are the submitters' own runs. Compare them only within one `suite_version`.

其他人提交的成绩，每个 harness 版本一个目录。格式与规则见 [CONTRIBUTING.zh-CN.md](../../CONTRIBUTING.zh-CN.md#如何提交成绩)。
这些数字由提交者自己运行得到，只在同一个 `suite_version` 内比较。
